# Isaac Sim 6.0.1 first WebRTC launch

Date: 2026-08-27

## Result

The pinned Isaac Sim 6.0.1 container launched successfully on GPU 1 and reached
NVIDIA's documented ready marker:

```text
[242.254s] Isaac Sim Full Streaming App is loaded.
```

The container remained healthy. From macOS, TCP 49100 on the GPU host's
Tailscale address accepted a connection. The native Apple-silicon WebRTC client
2.0.0 was downloaded from NVIDIA, matched the published MD5 checksum, passed
macOS code-signature and notarization checks, and launched.

Visual confirmation of the calibration scene remains a human acceptance step.
Do not close milestone M0 until the scene is visible in the macOS client.

## Reproduction

```bash
./tools/isaac check
./tools/isaac up
./tools/isaac status
```

Connect the NVIDIA Isaac Sim WebRTC Streaming Client to `100.76.65.1` while
Tailscale is active. Only one client can connect to an Isaac instance at a
time.

Stop and restart without deleting the persistent cache:

```bash
./tools/isaac stop
./tools/isaac restart
```
