# Active release — R1 Scientific Reef Atlas

## User-visible completion statement

A scientist can add an authorized reef survey, inspect a scientifically honest
3D site at real scale, trace every displayed asset to its evidence, and compare
published site versions without editing code.

## Release acceptance tests

- [ ] Process a new authorized survey from one manifest without manual scene editing
- [ ] Pass documented scale, orientation, anchor, datum, coverage, and reconstruction-error tolerances
- [ ] Resolve every displayed asset to source, licence evidence, recipe, and checksums
- [ ] Meet the agreed streaming and navigation performance targets on the GPU and Mac
- [ ] Reproduce the published reef version and validation report from a clean machine

No task above can be checked merely because a demo appears to work. It requires
reviewable evidence linked to a versioned release candidate.
