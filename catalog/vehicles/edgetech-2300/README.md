# EdgeTech 2300

A combined side-scan and sub-bottom towfish, the one KAUST tows. In the catalogue from EdgeTech's datasheet; drag, added mass and the tow cable are assumed. No thrusters: a dive flies it by asking for a tow — `"tow": {"speedKn": 4, "headingDeg": 90, "cableOutM": 60, "frequencykHz": 850}`. Built by `hardware/towfish/package.py`.
