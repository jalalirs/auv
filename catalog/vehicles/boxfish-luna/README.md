# Boxfish Luna

A hovering reef AUV that can also be flown on a fibre tether: built for the repeat visual survey of reef and fish that reef programmes ask for. In the catalogue as a reference vehicle, from Boxfish's published figures. What they do not publish — thruster layout and figures, hydrodynamic coefficients, lenses, colours — is assumed, and `dynamics.json` says which. Built by `hardware/luna/package.py`.
