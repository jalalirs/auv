# Applications

Interfaces used by people.

| Application | Who uses it |
| --- | --- |
| `client/` | Scientists and engineers: choose a place and a vehicle, fly a dive, watch it, replay it. An Electron application, and the thing this platform is for. |
| `console/` | Whoever administers an institution: who has been granted what, which queues exist, what the platform refused and why. Static assets behind nginx, which proxies the API on the same origin so the session stays a cookie. |

This table said `web/` for weeks. There has never been an `apps/web`. The two
applications that do exist were not listed, so the only index of them named
neither — which is the same failure as a help string that omits half the
assemblages it accepts.

A field operator application belongs here when there is a field mission system
for it to operate (R5). It is not present, because it would have nothing to do.
