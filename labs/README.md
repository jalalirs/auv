# Labs

Start with [Lab 03 — First Dive](03_first_dive/README.md) for the first complete
GPU simulation and Mac visualization workflow. Labs 00–02 remain the focused
concept exercises that explain the ROS graph, frames, and control underneath it.

Labs are guided learning exercises. Each lab should state prerequisites, a small
objective, commands to run, observations to make, and a completion check. Labs
may use production packages but should not duplicate their implementation.
