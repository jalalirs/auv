# OpenFish reference files

Downloaded 19 September 2026 from the OSF registration
https://doi.org/10.17605/OSF.IO/FB5VH (TU Delft, van den Berg, Scharff,
Rusák, Wu; HardwareX 2022). Licence CC BY-SA 4.0. Kept here so the head
redesign can be checked against the parts it has to mate with, and so the
tail, ribs and mould can be printed unchanged.

Part numbers follow the paper's table. STLs print; DXFs are cut from sheet;
the two Parasolid files are the full assemblies.
