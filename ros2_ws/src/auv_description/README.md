# auv_description

Owns the vehicle's physical and visual definition:

- frame tree and coordinate conventions;
- URDF/Xacro composition;
- mass, inertia, buoyancy reference, and collision geometry;
- thruster and sensor placement; and
- version-controlled meshes small enough to belong in Git.

The first model will be intentionally simple and parameterized before any
realistic CAD is introduced.
