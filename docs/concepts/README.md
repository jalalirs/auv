# Concepts

Concept notes explain ideas in our own words and connect them to running code.
Initial topics will include:

- marine coordinate frames and sign conventions;
- hydrostatics and hydrodynamics;
- thruster allocation and control loops;
- underwater navigation sensors;
- state estimation and observability;
- acoustic communication; and
- oceanographic measurement.

Prefer a short note linked to an experiment over a large disconnected summary.
